# Glosar pitch: etichete EN → RO

Interfața Loopwise trece în română (redesign v2). Tabelul de mai jos arată cum se numesc acum butoanele și secțiunile din scriptul de pitch. Sursa unică a textelor este `src/components/app/copy.ts`.

Coloana „Din etapa” arată când apare eticheta nouă în aplicație: 1 = shell-ul și componentele comune; 2–5 = paginile refăcute în etapele următoare.

## Etichetele din pitch

| Eticheta veche (EN) | Eticheta nouă (RO) | Din etapa |
|---|---|---|
| Run learning loop | Rulează bucla de învățare | 2 (și pasul din Ajutor: 1) |
| Turn into campaign | Transformă în campanie | 4 |
| Simulated history | Istoric simulat | 1 |
| Uses learning | Aplică o lecție | 3 |
| Create & test campaign | Creează și testează campania | 3 |
| Recommended | Recomandată | 3 |
| Edit in Adobe Express | Editează în Adobe Express | 3 |
